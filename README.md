# Memory App

A basic memory card-matching game built with **React + Vite**.

**Features:**
- 4×4 grid of emoji cards (8 pairs)
- Move counter and match counter
- Game timer with best-time tracking (persisted in `localStorage`)
- "New Game" button reshuffles the deck
- Win message when all pairs are matched

## Stack
- React 18
- Vite 5

## Scripts
- `npm install` — install dependencies
- `npm run dev` — start dev server
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build
